TypeScript: Додає статичну типізацію до JavaScript. Це допомагає виявляти помилки на етапі розробки (до запуску коду), 
покращує підтримку коду (особливо у великих проєктах) та робить його 
самодокументованим (легше зрозуміти, які дані очікує функція чи компонент)

Vue Router: Забезпечує створення SPA (Single Page Application), дозволяючи користувачам переходити між сторінками (компонентами) 
без повного перезавантаження браузера, що значно покращує користувацький досвід та швидкість роботи. Підтримує ліниве завантаження 
для оптимізації початкового завантаження.

ЛАБОРАТОРНА 5
Кроки виконання
1. Встановлення Tailwind CSS в проект
2. Налаштовуємо vite: підключаємо/імпортуємо tailwind, підключаємо стилі у vue
3. Рефакторимо файли: UserCard.vue, ContactView.vue, App.vue
4. Прописуємо код для додавання dark mode

У компоненті UserCard.vue умовні стилі для властивості isActive були реалізовані 
за допомогою динамічного прив'язування класів Vue (:class).

Переваги Tailwind CSS: 
швидкість розробки; 
стилі є локалізованими (всі правила елемента видно одразу), що покращує контекст;
завдяки компіляції розмір CSS мінімальний.

Недоліки Tailwind CSS:
захаращеність розмітки довгими списками класів, що може погіршити читабельність HTML;
